# java-calculator-precourse

## 기본 기능
1.  빈 문자열 입력 처리 (0 반환)
2. 쉼표를 구분자로 하는 문자열 파싱
3. 콜론을 구분자로 하는 문자열 파싱
4. 기본 구분자(쉼표, 콜론 등) 혼합 사용 지원
5. 파싱된 숫자들의 합 계산

## 커스텀 구분자 기능
1. 커스텀 구분자 형식 파싱
2. 커스텀 구분자를 이용한 문자열 분리 및 합 계산

## 유효성 검증
1. 음수 입력시 IllegalArgumentException 발생
2. 숫자가 아닌 문자 입력 시 처리
3. 잘못된 형식 입력 시 처리

## 입출력
1. 사용자 입력 받기
2. 결과 출력 ("결과: " + 값 형식)
